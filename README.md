# Hotkey
Hotkeys

## Installation
clone this repo and ```cd Hotkey```\
then ```mvn package```

the correct jar is the one WITHOUT original in its name\

run ```java -jar <path to jar>```

## Config
by default Ctrl+Alt will be mapped to open Dolphin, if your system do not have Dolphin, it probably will crash, sorry :3

config file is stored in ```~/.config/hotkeys```\

config format is: KEY+KEY+...=COMMAND (an example is provided in the default config)
